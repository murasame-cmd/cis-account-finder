# CIS Account Finder

Утилита для аудита собственного публичного цифрового следа по российскому номеру телефона.

Программа ищет только публично индексируемые страницы через официальный Yandex Search API и показывает найденные ссылки. Это не проверка скрытой регистрации аккаунтов.

## Ограничения и приватность

- Используй программу только для собственного номера или при явном согласии владельца номера.
- Номер передаётся Yandex Search API в составе поисковых запросов.
- Программа не обращается к закрытым API VK, Telegram, WhatsApp, Viber и других сервисов.
- Не обходит авторизацию и CAPTCHA, не использует адресные книги или GetContact.
- Результат поиска не доказывает, что найденный профиль принадлежит владельцу номера. Каждую ссылку нужно проверить вручную.
- Выполняется один запрос на каждый домен; массовой загрузки списков номеров нет.

## Поддерживаемые публичные домены

VK, Одноклассники, TikTok, Mail.ru, публичные страницы Telegram, WhatsApp (wa.me), Viber, Avito и MAX.

Полнота результатов зависит от поискового индекса. Отсутствие совпадений не означает отсутствие аккаунта.

## Требования

- Python 3.10 или новее.
- Ключ Yandex Search API и Folder ID в Yandex Cloud.
- Доступ к интернету.
- Внешние Python-библиотеки не требуются.

## Установка в Kali Linux / Ubuntu / WSL

    git clone https://github.com/murasame-cmd/cis-account-finder.git
    cd cis-account-finder
    python3 --version
    python3 cis_account_finder.py --self-test
    python3 cis_account_finder.py --setup
    python3 cis_account_finder.py

Во время запуска программа попросит подтвердить, что проверяется собственный номер или номер с явного согласия владельца. Затем попросит подтвердить начало поиска и отдельно спросит, сохранять ли отчёты.

## Получение ключа Yandex Search API

Официальная инструкция:
https://aistudio.yandex.ru/en/docs/search-api/quickstart/

REST API reference:
https://aistudio.yandex.ru/ru/docs/search-api/api-ref/WebSearch/search

Используется endpoint:
https://searchapi.api.cloud.yandex.net/v2/web/search

Ключ API вводится скрыто и сохраняется локально в:
~/.config/cis-account-finder/config.json

На Linux программа пытается установить права 700 для каталога и 600 для файла. Не публикуйте этот файл, не отправляйте его в чат и не добавляйте в Git. Файл config.json добавлен в .gitignore.

## Отчёты

При согласии пользователя отчёты TXT и JSON сохраняются в:
~/cis-account-finder-reports/

Каталог и файлы получают ограниченные права доступа, если ОС это поддерживает.

## Диагностика

Если получаете HTTP 401 или 403, проверьте API key, Folder ID, права ключа, подключение Search API и квоты Yandex Cloud.

Если поиск ничего не находит, это может означать лишь то, что поисковая система не проиндексировала публичные страницы с таким номером.
